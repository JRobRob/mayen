MAYEN WEB V3

CAMBIOS PRINCIPALES
- Carrusel de Inicio convertido en carrusel multimedia puro: sin títulos ni descripciones externas.
- Admite imágenes (JPG, PNG, WebP, etc.) y videos (recomendado MP4/WebM; MOV depende del navegador).
- El elemento activo aparece grande al centro; anterior y siguiente permanecen visibles, más pequeños y con ligera rotación.
- Flechas laterales y puntos inferiores permiten navegar.
- Rotación automática cada 6 segundos.
- Si el usuario reproduce un video, la rotación automática se pausa. Al terminar el video, avanza al siguiente elemento.
- El gestor local permite agregar imágenes o videos al carrusel con un único selector de archivo.

USO
1. Ejecuta ABRIR_GESTOR.bat.
2. En "Agregar al carrusel", pulsa "Seleccionar archivo".
3. Elige una imagen o video.
4. Pulsa "Agregar al carrusel".
5. Abre "Ver sitio" para comprobar el resultado.

RECOMENDACIONES DE MEDIA
- Para que el carrusel se vea consistente, usa piezas horizontales cercanas a 16:9 (por ejemplo 1600x900 o 1920x1080).
- Para video web, MP4 H.264 es la opción más compatible.
- Comprime los videos antes de publicarlos para evitar una página lenta.

El catálogo de productos y el resto del gestor de V2 se mantienen.
